# Проверка NEON CLASH

Проверено на macOS, Apple M4 / Metal, Rust 1.95.0, 10 октября 2026.

- `cargo fmt --check`: успешно.
- `cargo clippy --offline --all-targets -- -D warnings`: успешно, включая нативный проверочный пример.
- `cargo test --offline`: 26 тестов, 0 ошибок. Покрыты меню, бой, защита, комбо, индивидуальные спецприёмы, броски, раунды, физика, обучение, ИИ, snapshot/restore и детерминизм.
- 18 сочетаний бойцов, сложности и seed: ИИ вступают в бой и завершают раунд.
- GPU: кадры меню, выбора бойца, всех трёх арен, результата и справочника проверены визуально; изменение хеша мира при скриншоте не обнаружено.
- Настоящий release-процесс через MCP: выбор бойца, движение и **4 попадания / 284 урона** выполнены только клавиатурными событиями; snapshot восстановлен с точным хешем.
- Запись боя воспроизведена: **149 тиков, world hash match**. Машинный отчёт: `mcp-report.json`.
- `Play.command --help`: успешно; готовая `.app` прошла `codesign --verify --strict`.

Обновление Full HD: окно **1920×1080 физических пикселей**, камера с масштабом 2; логическая сцена 960×540 сохранена. Все GPU-кадры пересняты в 1920×1080, размеры PNG проверены по IHDR, полный кадр проверен визуально. MCP и replay повторно прошли на обновлённом исполняемом файле.

Нативный оконный прогон обновлённой release-сборки: поверхность AIGE **1920×1080**, **170 показанных кадров за 180 тиков, 0 ошибок рендера и симуляции**, меню и бой пройдены. Отчёт: `native-report.json`; изображение: `native-window.png`.

В ходе первоначальной разработки повторный оконный тест был ограничен заблокированным экраном macOS. После разблокировки оконная проверка Full HD прошла. `scripts/verify_native.sh` явно обнаруживает заблокированный экран и не объявляет такой запуск успешным. Права доступа и блокировка экрана не изменялись.

Перед публикацией зависимости AIGE переведены с абсолютных локальных путей на GitHub и закреплены на исходном commit `f998236bc44bf4683b1d8b607e037bb7ef70c040`. Повторно прошли fmt, Clippy, все 26 тестов и release-сборка. Нативная проверка новой сборки: **172 показанных кадра за 180 тиков, 1920×1080, 0 ошибок**. Архив релиза распакован в отдельную временную папку: подпись приложения, запуск `Play.command`, MCP-комбо и replay проверены на распакованном исполняемом файле. Для архива публикуется `SHA256SUMS`.
